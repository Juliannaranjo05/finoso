🛠️ Herramientas de Base de Datos

Panel de administración y sincronización de estructura BD

📋 ¿Qué encontrarás aquí?

Herramientas para comparar, exportar y sincronizar la estructura de tu base de datos con finoso.sql

🔍 Comparación y Exportación

👁️ Ver Estructura Actual

Muestra todas las tablas, columnas, índices y foreign keys de tu BD actual en formato detallado y legible.

Ver Estructura

📥 Exportar Estructura SQL

Genera un archivo SQL con la estructura actual (sin datos) para comparar con finoso.sql

Exportar SQL

🔄 Scripts de Actualización

🗑️ Eliminar auditoria_pagos

Elimina la tabla experimental auditoria_pagos que nunca se usó

Ejecutar

🔧 Actualizar usuario_codigo_descuento

Agrega el campo id_reloj y limpia registros antiguos

Ejecutar

🔄 Fix id_orden en códigos

Corrige id_orden NULL para códigos aplicados

Ejecutar

🧪 Otros Scripts

📊 Agregar monto_pagado

Agrega el campo monto_pagado a la tabla orden

Ejecutar

💳 Crear descuentos_aplicados

Crea la tabla descuentos_aplicados (si se necesita)

Ejecutar

⏰ Resetear relojes prueba

Marca relojes de prueba como disponibles

Ejecutar

⚠️ Precauciones Importantes

  • Haz backup de tu base de datos antes de ejecutar cualquier script
  • Los scripts de actualización modifican la estructura de la BD
  • Los scripts de comparación solo leen, no modifican nada
  • Revisa los resultados antes de aplicar cambios en producción

📝 Flujo Recomendado

  1. Ver Estructura Actual → Revisar qué hay en tu BD ahora
  2. Exportar Estructura SQL → Generar archivo para comparar
  3. Comparar con finoso.sql usando VS Code o DiffChecker
  4. Identificar diferencias (campos que sobran o faltan)
  5. Ejecutar scripts necesarios para sincronizar
  6. Actualizar finoso.sql con la estructura final
